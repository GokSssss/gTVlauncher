## Русский

### Что нового
- **Запомнить экран** Wi-Fi/Bluetooth: открыть нужное меню вручную → **Назад** → проверить переход → подтвердить.
- Чёткое выделение кнопок выбора.
- Подсказка долгого OK под системными значками, без сдвига рабочего стола.

**Установка:** TV APK поверх прежнего лаунчера. Телефонный **To TV1.0.4** не менялся; приложен для новых установок.

Для запоминания нужна включённая пользователем служба специальных возможностей. Сеанс максимум2минуты, без текста экрана и истории процессов. Доступность конкретной панели зависит от прошивки.

**Проверочный выпуск:**176 native проверок на эмуляторе API28; физические OEM панели требуют проверки на устройстве. Android5.0+, min21/target34. Чистая сборка из SOURCE совпала с APK, подпись прежняя. Файлы на Drive и GitHub одинаковые.

## English

### Changes
- **Capture screen** for Wi-Fi/Bluetooth: open the menu manually → **Back** → test → confirm.
- Clear focus on chooser buttons.
- The long-OK hint appears below the system icons without moving the home grid.

**Install:** update the TV APK over the previous launcher. Phone **To TV1.0.4** is unchanged and included for new installations.

Capture requires the user-enabled Accessibility service. Sessions last up to2minutes; no screen text or process history is collected. A specific panel may not be directly accessible on some firmware.

**Preview release:**176 native assertions on an API28 emulator. Physical OEM panels still need device testing. Android5.0+, min21/target34. A clean SOURCE build matched the APK; signing identity is unchanged. Drive and GitHub use the same files.
