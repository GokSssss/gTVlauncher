13.11.2026 — True TV Launcher2.2.12/code242: выбор и запоминание экранов.
Прямое указание владельца: чёткий фокус кнопок выбора, временная подсказка под системными значками и явное запоминание открытого вручную экрана с завершением по Назад, проверкой и подтверждением. Отслеживается системное окно (package/class), не процесс. Никакого обещания восстановить внутренний Fragment производителя по одному имени Activity.
HomeActivity: подсказка долгого OK Wi-Fi/BT теперь собственный временный PopupWindow непосредственно под header,6секунд, без фокуса/касания/постоянных строк и резерва. Сетка не сдвигается; пауза закрывает подсказку. Короткое OK, состояния/36dp значки и независимые ключи экранов прежние.
RadioScreens: все управляющие кнопки используют Ui.tvButton — контрастный серый фокус с тёмным текстом и рамкой; ListView имеет свой видимый селектор. Каталог добавляет реальные exported системные LEANBACK_SETTINGS и публичные Wi-Fi/BT действия для доступных общих Settings-хостов. Приватные Activity, скрытые grants, guessed Fragment extras и обход разрешений не применяются. Поиск/режим/последняя строка и прокрутка сохраняются как раньше.
Новая кнопка Запомнить экран запускает ScreenLearning только по явному нажатию и только через уже включённую пользователем службу лаунчера. При её отсутствии — инструкция и публичные настройки специальных возможностей, без автоматического включения. Один сеанс максимум2минуты (Handler + elapsedRealtime); в ожидании eventTypes0 и флаг перехвата клавиш снят. Только на время сеанса TYPE_WINDOW_STATE_CHANGED и BACK; другие клавиши проходят. BACK завершается на отпускании, окно не откатывается раньше захвата. Наблюдение/фильтр выключаются до возврата Home и проверки. Отключение/прерывание службы отменяет сеанс; автоматического восстановления нет.
Хранится один проверенный ComponentName в памяти, без текста/узлов/снимков/истории процессов/выгрузки/постоянных логов. PackageManager-проверка в одном ограниченном worker, очередь8 и generation от устаревших ответов. Android9 накапливает packageNames в AccessibilityServiceConnection: null не расширяет прежний фильтр. Поэтому при явном старте один раз задаётся конкретный список системных пакетов; вне сеанса события отключены. Предыдущие stop/power операции дополнительно ограничены своими допустимыми пакетами. Новых фоновых опросов нет.
После Назад Home предлагает Проверить запомненный экран / Выбрать другой / Отмена. Проверка запускает доступную Activity с публичным WIFI_SETTINGS/BLUETOOTH_SETTINGS. Исходные чужие Intent extras Android не раскрывает. На возврате обычный вопрос подходит ли экран; только Да сохраняет нужный wifi_route или bluetooth_route. Отказ/тайм-аут/недоступный компонент не меняет сохранённое. Если OEM Bluetooth-панель — внутренний Fragment без доступного перехода, этот режим может открыть общий раздел: нужно отвергнуть результат и выбрать другой вариант. Точная панель фотографии не подтверждена.
minSdk21/target34 прежние; Android9 — стенд, не ограничение универсальности. ToTV1.0.4/code104 и16 входов phone/bridge не менялись. Самостоятельного переноса механик из исходного Simple Launcher не заявляется; новая логика написана для проекта, runtime сторонних лаунчеров не добавлен.
